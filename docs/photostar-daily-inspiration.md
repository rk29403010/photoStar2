# PhotoStar2 Daily Inspiration

This is the durable repository copy of the daily PhotoStar2 research and inspiration feed.

The daily review looks at the current `main` codebase plus external photo-archiving, restoration, editing and family-history software; image-processing libraries; AI models; relevant research; and art/design/storytelling work. Research items should include an official or author-provided demo and/or codebase when one can be found.

## How worker threads should use this file

- This is **inspiration and product/design context**, not an approved roadmap or implementation order.
- If Robin refers to one of these named ideas, search this file for the term before asking him to restate it.
- Check the current code and `main` branch before acting on an older idea; implementation may have moved on.
- Prefer synthesis over copying another product wholesale.
- Keep historical evidence, uncertainty and provenance distinct from AI inference or creative interpretation.

Future daily entries should be added under an unmistakable heading of the form:

`## YYYY-MM-DD — Short theme`

If a run for that date already exists, replace/update that day's section rather than duplicating it.

## Earlier feed concept index

The full daily feed before this repository log lived in ChatGPT. These names are retained here so worker threads can recognise later references; future entries will contain the full daily brief.

- **Object Threads / Find this again** — follow the same physical object through the archive using masks and visual identity.
- **Claims and Evidence** — distinguish known facts, human claims, AI inference, disagreement and provenance.
- **Selective Restoration** — analyse different regions/degradations and apply appropriate restoration rather than one global AI pass.
- **Authenticity Map / semantic guardrails** — record which areas were transformed or generated and verify that important identities/text/evidence survive edits.
- **Album Archaeology** — preserve album pages as historical objects while extracting and linking individual photos, handwriting and page layout.
- **Artefact / Photograph above Asset** — distinguish the historical photograph/object from its scans, crops, derivatives and other digital manifestations.
- **Model Lab / Gold Set** — benchmark candidate AI models on representative PhotoStar family photographs before integrating them.
- **Reference-assisted restoration** — use other real photographs of the same person/object/scene as evidence when restoring damaged images.
- **Place Threads** — recognise the same physical place across decades and link family photos, maps and modern revisits.
- **Same / Similar / Echo** — distinguish the same physical instance from merely similar objects and looser visual/cultural echoes.
- **Memory Session / Family Chorus** — record spoken recollections around a photograph and retain timestamped audio as evidence behind extracted claims.
- **Memory Spaces / Scene Groups** — infer relative camera viewpoints across photographs of the same room/event and browse actual historical viewpoints spatially.
- **Find this, but…** — composed retrieval using a reference photo or mask plus a textual change/instruction.
- **Micro-Moments** — detect near-consecutive real photographs and treat them as a short sequence; interpolate only as an explicitly marked derivative.
- **Photo Dating Workbench / Date Detective / Time Fog** — combine many weak date clues into explainable ranges rather than false precision.
- **People Constellations** — use photographic co-occurrence to explore relationships and improve uncertain face identification.
- **Photo Families** — group multiple files/scans/prints that represent the same original photographic exposure and merge knowledge, not files.
- **Explainable Discovery** — expose why results are related and let the user steer which relationship signals matter.
- **Contribution Inbox / Question Packs** — ask relatives small, targeted questions and treat responses as attributed proposals rather than silent metadata edits.
- **Roll Reconstruction / Follow the Photographer** — recover likely original shooting sequences/contact sheets from disconnected scans.
- **Maker / Through Their Eyes** — model who took a photograph or which studio made it, including inference from sequence absence and studio imprints.
- **Context Engine / Context Dial** — retrieve tightly relevant external historical maps/images/context around a family photo while keeping it distinct from the family archive.
