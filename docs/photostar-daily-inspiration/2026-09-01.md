# PhotoStar2 Daily Inspiration — 1 September 2026 — Home Movie Threads

## Best next idea — Home Movie Threads

Treat home movies as a searchable extension of the photograph archive rather than as a separate video library. The useful unit is a timestamped `VideoMoment`, not merely a whole video file.

A still photograph, person, place or text query should be able to return exact moments inside old films, with playback beginning just before the match. This would materially extend Memory Bundles by allowing an event to point into a portion of a video rather than attaching a whole recording.

### Practical first experiment

1. Use FFmpeg scene detection and keyframe extraction on a few old family videos.
2. Embed sampled frames in the same visual space used for still-photo retrieval where practical.
3. Search those keyframes using known still photographs from the same events.
4. Return the best timestamp matches and judge them manually.

No video LLM is required for this first test.

### Relevant research and code

- **WISE (Oxford VGG)** — open-source multimodal search over images, video and audio. Official code: https://gitlab.com/vgg/wise/wise
- **Lighthouse (LINE)** — text-to-video moment retrieval and highlight detection, with pretrained models and an official Gradio demo in the repository: https://github.com/line/lighthouse
- **WorldMM (CVPR 2026 Highlight)** — long-video reasoning via episodic, semantic and visual memory rather than one monolithic representation: https://worldmm.github.io/

### UI direction

Instead of opening a 90-minute VHS transfer at 00:00, show recovered moments such as:

- 00:13:42 — Mum and Dad in garden
- 00:38:17 — probable Christmas dinner
- 00:51:20 — railway station

Actions: `Previous moment` · `Next moment` · `See related photos`.

### Provenance rule

If genuine moving footage survives, it should outrank synthetic animation. A derived still from video must retain source filename and exact frame timestamp.

## Creative concept — Still to Motion

Open a family photograph and, where PhotoStar finds genuine matching cine footage, offer **See the moment move**. Transition from the still into the real recording a few seconds before the matching frame. This is archival linkage rather than AI animation.

## Recommendation

Prototype photo-to-video matching before building general video UI. If cross-media retrieval works reliably on a handful of real family videos, make `VideoMoment` a first-class entity.
