## Best next idea — Object Lives / Find this thing again

PhotoStar should let a user point at a meaningful physical object in one photograph — a chair, necklace, toy, clock, car, painting, caravan, vase — and ask **Find this object elsewhere**.

The important distinction is **same physical object**, not merely the same category. Confirmed matches become a durable Object entity linked to the photographs, people, places and periods in which it appears.

Example: a distinctive chair appears in a 1954 sitting room, a 1968 family portrait, a 1989 house-clearance photograph and a modern photograph in another relative's home. PhotoStar can turn those appearances into an evidence-backed object biography without inventing the missing history.

**User value:** high for inherited family archives; objects can bridge generations when people, places and dates are uncertain.

**Likely effort:** low-medium for user-seeded retrieval; medium-high for reliable archive-wide discovery.

## Practical UI

From a photo:

1. draw/click the object;
2. `Find this again`;
3. show a ranked contact sheet of candidate regions;
4. one-click `Same object`, `Similar only`, `Not this`.

After two or three confirmations, PhotoStar can use them as multiple exemplars and search again. Do not ask the user to name or catalogue every object first.

An Object page can then show an appearance strip through time, people photographed with it, places it appears, stories/testimony about it, and unresolved candidate matches.

## Why this fits PhotoStar now

PR #42 provides the right semantics: a detected/matched region is machine evidence; `these regions depict the same physical object` is a proposition; user confirmation is a durable decision. VisualRegion can provide the stable link from the object to the relevant pixels. This also connects directly to Temporal Triage, Place Solver, Background Detective, Photo Conversations and Story Cut.

Objects can become useful constraints. A confirmed heirloom known to have entered the family after 1962 can challenge a proposed 1950s date; the same caravan can connect otherwise weakly related holiday photographs; a piece of furniture can support same-house hypotheses.

## Current product/design signal

Current family-archive products are increasingly connecting photos, people, events and stories, but object-centred family history remains comparatively underdeveloped. Memmie connects photos into shared family Moments; Picturesque attaches voice stories to photos; Tonfotos links people and family relationships; MyHeritage Scribe AI extracts historical clues from photographs/documents. Heriteo and TapNota approach the problem from the other direction by cataloguing heirlooms/keepsakes and attaching family memories and context to physical objects.

The synthesis for PhotoStar is not a separate heirloom inventory. It is to let **objects emerge naturally from photographs**, then connect them to physical-object knowledge only when useful.

## Model Lab candidate — SAM 3 / SAM 3.1

Meta's SAM 3 supports text, point/box and **visual exemplar** prompts and can find/segment matching concepts; Meta released official code and a playground. SAM 3.1 (March 2026) adds faster shared-memory multi-object tracking, mainly relevant if Object Lives later extends into home movies.

Official resources:
- Project/playground: https://ai.meta.com/research/sam3/
- Official code: https://github.com/facebookresearch/sam3
- Research page/paper: https://ai.meta.com/research/publications/sam-3-segment-anything-with-concepts/

This is a strong segmentation/exemplar-discovery candidate, but concept matching is not the same as proving physical-object identity. Treat output as candidates only.

## Verification candidate — LightGlue

For rigid/textured objects, local feature matching can provide a second, quite different signal. LightGlue matches sparse local features between image pairs; the authors provide official code, pretrained weights, a Colab and a Hugging Face demo.

Official resources:
- Code/project: https://github.com/cvg/LightGlue
- The repository links the authors' Colab and hosted demo.

A sensible pipeline is therefore broad candidate retrieval first, then crop/region embeddings and/or LightGlue verification for plausible rigid objects. It will be weak on deformable objects, major appearance change and tiny low-resolution regions, so human confirmation remains important.

## Storytelling/design precedent — object biography

The Ashmolean's Object Biographies project frames an object's history as where it was made, how it was used, how its meaning changed and who owned it, while explicitly warning that parts of an object's story may remain uncertain. That maps unusually well to PhotoStar's evidence model.

- https://britisharchaeology.ashmus.ox.ac.uk/east-oxford/object-bios.html

The Smithsonian's Hannah Nicholson Album Quilt is a good concrete example: inscriptions, names, dates and family stewardship make the object itself a family record rather than mere background scenery.

- https://www.americanhistory.si.edu/ne/collections/object/nmah_556204

## Creative concept — The Things That Stayed

Generate a story view centred on persistent objects rather than people:

`1954 → 1968 → 1989 → 2026`

The same chair, clock, necklace or toy appears in genuine photographs as homes and people change around it. Captions should stick to accepted evidence: who appears, where/when known, and what family testimony says about the object.

This could produce unusually strong family storytelling without synthetic imagery or generic AI prose.

## Experimental concept — Object handover

When an object disappears from one household/person's photographs and later appears with another, PhotoStar can propose a possible **handover**:

> The same clock last appears at Margaret's house in 1987 and first appears at Jean's in 1989. Did it move between them?

One human answer could resolve ownership/provenance and add context to many photographs. Never infer inheritance/death from the visual sequence alone.

## Best next experiment

Take 30 distinctive real objects known to recur across a family archive. For each, mark one region in one photograph and retrieve candidate regions from a few thousand images. Measure top-20 recall and, more importantly, how many candidates a human must inspect before the first correct recurrence appears.

Start with existing image embeddings/crops if possible. Benchmark SAM 3 exemplar prompting and LightGlue only against this controlled set. Do not run expensive object discovery over the whole archive until the seeded workflow proves useful.

## Recommendation

**Object Lives / Find this thing again** is the best next idea to explore. It is user-seeded, explainable, fits the semantic/evidence architecture, and can create new links across people, places and decades without requiring a new global analysis pass. The first useful version can be deliberately modest: select an object, retrieve candidates, confirm matches, then let PhotoStar build the biography from real photographs and attributed evidence.
