## Best next idea — Stand Here Again / Rephotography Mission

Turn a solved historical viewpoint into a field task: guide someone back to the physical camera position and help them take a modern photograph from the same viewpoint.

This materially develops Place Solver, Viewpoint Graph and Context Window. Instead of stopping at “this was probably taken here”, PhotoStar can say “we think the photographer stood here — recreate it”.

A first version does not need AR or 3D reconstruction. If a photo has a confirmed/likely location, send a mobile-friendly mission containing the old photograph, map pin, optional notes, and a translucent/edge overlay. The user aligns persistent landmarks in the live camera, captures the new image, and PhotoStar stores the result as a linked rephotograph rather than an unrelated new asset.

User value: high for houses, streets, holiday locations, schools and workplaces. Effort: low-medium for manual overlay guidance; medium-high for automatic pose guidance.

## UI

On a photograph with useful place evidence:

**Recreate this view** → map/location confidence → field camera.

The camera view can offer three escalating aids: ghost opacity, edge/landmark overlay, and directional hints (“move left”, “step back”, “camera slightly lower”). After capture, reuse PhotoStar’s overlay compositor to refine alignment and expose a then/now slider.

Store the relationship and evidence: `historic Photograph -> same-view proposition -> modern Photograph`, including who confirmed it and any geometric alignment result. A visually convincing overlay must not silently promote an uncertain location to fact.

## Current product sample

GhostViewer (https://ghostviewer.co.uk/) launched in 2026 and combines historic-photo discovery, a Ghost Guide Camera, manual landmark pairs and geometric alignment. Its documentation makes an important distinction between matching the viewpoint in the field and warping the final pair afterwards.

re.photos (https://www.re.photos/) now has an iPhone app whose live guide gives left/right/up/down/closer/farther cues and then finishes alignment automatically. SameView (https://sameview.app/en/) deliberately stays simpler: GPS guidance, reference overlay and markers, with alignment remaining user-controlled. Contour (https://contour.ltd/) uses contours/ghost overlays locally on iPhone for same-shot capture.

PhotoStar should not become another standalone rephotography app. Its advantage is that the mission starts from an evidence-rich family photograph and the resulting modern view returns to the same family/place graph.

## New research — HistReNeRF

Hughes & James, *HistReNeRF: Historic Image Relocalisation within Contemporary Neural Radiance Field Reconstructions* (15 Aug 2026), estimates a historic photograph’s 6-DoF camera pose inside a contemporary NeRF by matching adapted DINOv2 patch features to rays from the modern scene. On a dataset of 10,545 contemporary images and 230 archival photographs across three European landmarks, the paper reports average translation/rotation error reductions of 11%/16% for embedding-space adaptation versus pixel-space methods.

Paper: https://arxiv.org/abs/2608.15420

The paper states that official code/data are at `https://github.com/ARTUROLab/HistReNeRF`, but that repository currently returns 404 through the connected GitHub service. So there is **no usable official codebase/demo I can verify today**; do not plan implementation around it yet.

The underlying official DINOv2 implementation and demo remain available from Meta:
- code: https://github.com/facebookresearch/dinov2
- demo: https://dinov2.metademolab.com/

## Model Lab candidate — VGGT

VGGT (CVPR 2025 Best Paper) can infer camera intrinsics/extrinsics, depth, point maps and tracks from multiple images. The authors provide official code, pretrained models, a project page and interactive Hugging Face/Gradio demo:
- project/demo links: https://vgg-t.github.io/
- official code: https://github.com/facebookresearch/vggt

This is a better immediately testable research path than HistReNeRF. For a place with several confirmed family/modern photographs, benchmark whether VGGT can reconstruct enough stable geometry to estimate relative viewpoints and produce useful field guidance. It should remain Model Lab work until it proves robust on old scans with large scene changes.

## Practical improvement — Landmark Anchors

Allow a user to mark 2–6 durable points once: chimney corner, church tower, window edge, gatepost. Reuse those anchors for:
- Viewpoint Graph overlap;
- modern rephotography alignment;
- same-place verification;
- restoration registration;
- later automatic landmark proposals.

This is cheap, inspectable evidence and gives automatic methods something concrete to optimize against.

## Large-library UX — Missions, not another map

Place pages can surface a small actionable queue:

- **Recreateable now** — known accessible viewpoint, strong place evidence.
- **Needs location refinement** — town/street known but camera position uncertain.
- **Already recreated** — then/now pairs.

Rank for value: old family home with no modern counterpart beats the 18th near-identical holiday view. This turns archive exploration into occasional real-world activity without creating hundreds of chores.

## Creative concept — Family Tripod Marks

When several generations photographed the same doorway, garden, beach or viewpoint, align the genuine photographs around the inferred camera position and present a time stack: 1938 → 1964 → 1992 → 2026. The “tripod mark” is conceptual: the place from which the family repeatedly looked at itself/world.

No generated scene is needed. The creative result comes from precise alignment of surviving evidence.

## Experimental concept — Ghost Walk

For a place with several solved viewpoints, PhotoStar can build a short walking route: “5 family photographs can be revisited within 1.2 km.” Each stop shows only the relevant old photograph and capture guide. Back home, the new images become a coherent then/now Memory Bundle.

This materially develops Context Window: external maps/context help get you there, but the purpose is to create new first-party family evidence linked to the old archive.

## Best next experiment

Pick 20 historical family photographs at locations still accessible. For each, record the known location and take a modern candidate image. Test three levels:

1. manual opacity overlay;
2. edge/landmark guidance;
3. VGGT-assisted relative camera pose where enough reference views exist.

Measure time-to-good-match, alignment error on manually marked landmarks, and whether the guidance actually reduces retries. If simple landmark guidance gets most cases close enough, ship that before any NeRF/3D work.

## Recommendation

**Stand Here Again is the best next idea to explore.** It turns existing Place Solver/Viewpoint Graph intelligence into an unusually tangible outcome, reuses PR #37’s overlay semantics, and can start cheaply with human-visible landmarks. The ambitious research path — historical-to-modern 6-DoF relocalisation — is now becoming credible, but the newest directly relevant project’s promised code is not currently accessible, so PhotoStar should prototype the simple evidence-led workflow first.
