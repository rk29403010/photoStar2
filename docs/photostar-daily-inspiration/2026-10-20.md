## Best next idea — Colour Evidence Studio

An optional editor/viewer that allows a family B&W photograph to be coloured with a per-region evidence record. Example: a 1960s family portrait contains a distinctive coat. A colour slide of the *same coat* from a related event supplies a candidate colour. A period catalogue might suggest a plausible colour, while an unconstrained model output is only a visual interpretation. Do not imply that grayscale pixels uniquely determine hue.

### User experience

- Three explicit modes: **Restore original colour** (faded colour negative/print), **Evidence-guided colourisation** (B&W + supporting references), **Creative colourisation** (hypothetical).
- Region chip on click: `Colour: dark blue · basis: confirmed garment in colour slide #123 · source link · confidence: medium`. Other options: external historical reference, family recollection, unverified AI suggestion.
- Compare `Original | Evidenced colours | Creative interpretation` via swipe/side-by-side; original remains untouched; derivative exported with embedded/source-adjacent disclosure.
- **Colour Anchors** gallery lens: find B&W photos whose people, clothing or objects recur in known-colour photos. A ranked investigation queue, not an automated assertion.
- Don't conflate colour profile correction, fading restoration, and adding unknown colours. Check ICC input/display assumptions before evaluating output.

### Build plan / rough effort

1. Add colour-assertion data with regionId, swatch/colour-space, source asset or external citation, attribution, confidence, status and version; make human edits independent of machine analysis (2–4 days).
2. Add swatch picker + evidence chip + 3-way viewer; leverage existing masks and edit recipes (3–6 days).
3. Add `Colour Anchors` queue from related-photo observations and confirmed human relationships (2–4 days).
4. Only after a benchmark, experiment with a model plug-in. Allow explicit colour hints; never silently overwrite a human swatch. Model integration/packaging could take 1–2 weeks, especially Windows CPU/GPU support.

## Product comparison

- MyHeritage In Color (https://www.myheritage.com/help/en/articles/12852501-what-is-myheritage-in-color): preserves original separately and provides automatic colourisation; distinguish its simulated colours from actual colour restoration (https://www.myheritage.com/help/en/articles/12852503-what-is-myheritage-in-color-color-restoration).
- digiKam colour management (https://docs.digikam.org/en/color_management/color_management_basis.html): ICC profiles matter for input, display and print; colour accuracy cannot be judged from unmanaged screenshots.
- Mylio Photos editing (https://support.mylio.com/can-i-edit-photos-in-mylio-photos): tone, white balance, colour and auto-colour tools; PhotoStar should connect colour choices to source evidence, not merely improve appearance.
- FamilySearch Memories (https://www.familysearch.org/en/help/helpcenter/article/how-do-i-use-familysearch-memories-to-preserve-my-ancestors-life-stories): links family photos, documents, stories and audio; memories can be attributed colour evidence but are not automatically facts.

## Research and official/author resources

1. **DDColor**, Kang et al., ICCV 2023. Official author code (Apache-2.0): https://github.com/piddnad/DDColor ; official local Gradio demo: https://github.com/piddnad/DDColor/tree/master/demo ; author-linked Replicate-hosted playground: https://replicate.com/piddnad/ddcolor ; paper: https://arxiv.org/abs/2212.11613 . Automatic baseline; can hallucinate historically incorrect colours.
2. **UniColor**, Huang et al., SIGGRAPH Asia 2022. Author project/results: https://luckyhzt.github.io/unicolor ; official code and sample notebook: https://github.com/luckyhzt/unicolor and https://github.com/luckyhzt/unicolor/blob/main/sample/sample.ipynb ; paper: https://arxiv.org/abs/2209.11223 . Supports stroke/exemplar/text hints. Author's project has a demonstration video and local notebook; no verified hosted interactive upload demo.
3. **ColorFLUX**, Li et al., CVPR 2026. Official proceedings: https://openaccess.thecvf.com/content/CVPR2026/html/Li_ColorFLUX_A_Structure-Color_Decoupling_Framework_for_Old_Photo_Colorization_CVPR_2026_paper.html ; preprint: https://arxiv.org/abs/2603.28162 . Research separates structural and colour modelling, but no usable official author code or demo found as of this run. Do not imply deployability.
4. **DeOldify** historical baseline: official author's archived repository https://github.com/jantic/DeOldify ; archived since 2024, not a preferred new dependency.

## Art, ethics and experimental storytelling

- Marina Amaral's author page: https://marinamaral.com/about/ ; her Faces of Auschwitz collaboration: https://marinamaral.com/portfolio/faces-of-auschwitz/ . Meticulous contextual research can strengthen a colour interpretation but does not make it a recovered original.
- Watkins and Williams (2025) discuss ethical issues of colourisation and its effect on viewers: https://eprints.whiterose.ac.uk/id/eprint/224030/ . Scholarly critical article; no software demo/code expected or found.
- **The Colours We Know**: experimental exhibition mode where only genuinely evidenced colour regions appear in colour while the rest remains monochrome. Clicking each coloured island reveals its supporting source. The rest can be shown as optional alternative creative colourisations, clearly labelled. This can connect family photographs with surviving colour slides, catalogues and modern photographs without falsely claiming full historical certainty.

## Small benchmark

Take 20 B&W family photos with real corresponding colour exposures/objects, plus 10 ambiguous B&W images. Hide the colour references from model predictions and measure colour error for confirmed reference regions, model-to-model variability, subject boundary spill, identity/text preservation, user correction time, Windows processing cost, and proportion of assertions with defensible evidence. Test against manual swatches, DDColor, UniColor with hints, and an automatic baseline. No cloud uploads of private family material without explicit safety clearance.

**Recommendation:** start with the per-region colour-evidence swatch and comparison UI, *not* a new model. Historical honesty and a usable source-based workflow are the distinctive value.
