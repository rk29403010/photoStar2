# PhotoStar2 Daily Inspiration — 29 October 2026
## Voice Anchors — let people explain the photograph in their own words

**Best next idea:** Attach a *time-coded, attributed recording* to a photograph or a specific person/object within it. A spoken recollection remains the original evidence; a corrected transcript becomes searchable; any identity, date or location claims remain separate, reviewable propositions. This is more focused than the earlier general Memory Trail or family-question proposals: it defines a concrete audio-evidence workflow and exploits PhotoStar2's already-present testimony model.

### ★ Proposed feature: Voice Anchors

In a group photograph, a relative points to a person and says, “That's Aunt Jean, I think; she used to run the shop.” Record the voice locally and attach the **specific 12–20 second span** to the relevant face region. Display:
- **Listen (0:14–0:31)** — the unaltered recording, speaker and recording date.
- **Transcript** — editable transcription, with original machine output retained.
- **Possible identity: Jean** — *tentative testimony*, not a confirmed face identity.
- **Other clues:** shop ownership is a separate unverified biographical claim.
- **Disagreement:** if another contributor says “No, that's Joan”, show both attributed statements and keep the identity unresolved.

A transcript correction is **not** a historical fact correction. Speech-to-text confidence must never be promoted into identity confidence. Never infer that the speaker in a recording is the person depicted in the photograph.

#### Data/UX integration

Create an immutable audio asset (checksum, original format, capture date, consent/visibility), time-coded `audio_span` references, a transcript version chain, and links to existing photo/face/region/person/event semantic entities. Human assertions use the existing contributor/attestation machinery. Keep audio files in managed app storage, not the Git repository. Preserve offline operation and avoid automatic cloud uploads.

**Large-library navigation:** Add a small **Voices** filter in the existing gallery (Has recording / Mentioned in recording / Unreviewed transcript), plus transcript search with a seek-to-time result. Show one thumbnail per photo and an audio badge rather than introducing a separate competing photo gallery. In the single-photo view, clicking a highlighted region opens its corresponding voice excerpt.

| Priority | Increment | User value | Provisional focused effort |
|---|---|---|---|
| 1 | Import or record an audio clip, link it to a photo, identify contributor, play it | Capture memories immediately; no AI dependency | 3–5 days |
| 2 | Select audio span + image region, manually enter transcript, preserve versions | Precise, attributable evidence | 3–5 days |
| 3 | Transcript full-text search and gallery Voices filter | Find photographs from remembered spoken details | 2–4 days |
| 4 | Optional local transcription worker | Reduce transcription effort | 4–8 days after testing |
| Later | Speaker diarization, prompted questions, curated audio stories | Multi-speaker interviews and richer presentations | Research-dependent |

### Model and research lab — official resources and demo status

1. **[whisper.cpp](https://github.com/ggml-org/whisper.cpp)** — efficient C/C++ implementation of OpenAI's Whisper for local transcription. The project publishes an [official browser streaming example and source](https://github.com/ggml-org/whisper.cpp/blob/master/examples/stream.wasm/README.md) and an [author-linked browser demo](https://ggml.ai/whisper.cpp/stream.wasm/). Best first candidate for a Windows local worker; benchmark small models on actual family accents, names and recording quality. A browser demo is not proof that the packaged Windows integration will work.

2. **[WhisperX](https://github.com/m-bain/whisperX)** — [INTERSPEECH 2023 paper](https://www.robots.ox.ac.uk/~vgg/publications/2023/Bain23/bain23.pdf), word-level forced alignment and optional diarization. The author repository provides runnable command-line examples and embedded demonstration videos. It also documents **2026 context-aware interleaved batching** ([author-linked preprint](https://arxiv.org/abs/2608.31170)) aimed at better long-form contextual transcription; this is worth testing for family names but not assumed accurate. I found no verified first-party interactive upload demo. The separately branded `whisperx.app` explicitly describes itself as **unofficial**, so don't present it as the authors' demo. WhisperX's Python/CUDA dependencies make it a later, optional worker.

3. **[pyannote.audio](https://github.com/pyannote/pyannote-audio)** — official speaker diarization library, with [official Community-1 model card and runnable examples](https://huggingface.co/pyannote/speaker-diarization-community-1) and a model-linked [Colab notebook](https://huggingface.co/pyannote/speaker-diarization-community-1). Model access requires accepting terms. I found no verified official public interactive audio-upload demo. Useful for detecting speaker turns, **not** automatically naming speakers. Diarization is imperfect on overlap, quiet voices and archival recordings.

**Recommendation:** Begin with manual audio attachment and transcript search; add whisper.cpp only after measuring transcription errors on real recordings. Diarization can wait.

### Art, history and experimental concept

The [British Library's National Life Stories](https://www.bl.uk/about/projects/national-life-stories) demonstrates the long-term historical value of preserving first-person voices. [PhotoVoice](https://photovoice.org/ourwork/) uses participatory photography and storytelling, with an emphasis on whose perspective is represented. The [National Lottery Heritage Fund's oral-history guidance](https://www.heritagefund.org.uk/funding/good-practice-guidance/oral-history) recommends informed consent and, where appropriate, restricted access or embargoes for sensitive recordings.

**Experimental: The Photograph That Talks Back.** Inspired by Janet Cardiff's [*Her Long Black Hair*](https://cardiffmiller.com/walks/her-long-black-hair/) (2004), an audio walk that deliberately pairs voices, places and photographs. In PhotoStar2, select a street photograph and hear a relative's 15-second recollection while the image gently highlights the actual shop, person or doorway being discussed. Follow a verified link to another photo or a modern view; pause to see the original source and any contradictory recollection. No invented voices, lip-sync or fabricated historical dialogue. Effort: medium after Voice Anchors; optional export as an offline narrated story.

### Best next experiment

Test with 12 photographs and 5–10 minutes of voluntary, consented narration, including two people who disagree about a name. Start without AI. Measure attachment time, ability to jump from transcript to exact photo region, time to find a photo by a phrase spoken only in audio, preservation of contradictory testimony, and whether reset/re-analysis preserves every human decision. Then compare local whisper.cpp transcription to a human-corrected transcript; measure proper-name errors, elapsed time, model size and CPU memory on Windows.

This directly develops existing `memory`, `audio_span` and testimony foundations and creates archival value before any AI dependency.
