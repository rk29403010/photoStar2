### User journey
A user opens an undated street photo and chooses Investigate place. PhotoStar shows candidate locality from a sign, church or shopfront, plus three dated external references: historical OS map, aerial archive, gazetteer. Each reference records title, source URL, publication/survey date, rights and whether it merely supports a locality or identifies a precise viewpoint. User can accept, reject or mark uncertain; original evidence survives re-analysis.

### Practical changes and rough effort
1. Manual location hypothesis and source links (2–4 dev days): reuse semantic evidence; no coordinates required.
2. Place Detective drawer with historic-map deep link (2–4 days): prioritize images with signs/buildings and low location certainty; avoid a new map subsystem initially.
3. Date-sensitive place names and bounded geographic search (3–6 days): historical gazetteer, distinguish historic and modern names.
4. Location review queue for large archives (3–5 days): group by locality, decade, unresolved landmarks; never treat folder name as a verified place.
5. Optional viewpoint alignment and modern comparison (5–10+ days after validation): explicit user approval; preserve original and source rights.

### Current software, collections and research
- National Library of Scotland georeferenced maps and side-by-side viewer: https://maps.nls.uk/geo/explore/side-by-side/ ; updated family history guide 5 Nov 2026: https://www.nls.uk/tools-for-research/family-history/maps/
- Historic England Aerial Photo Explorer, currently over 540,000 digitised aerial images: https://historicengland.org.uk/images-books/archive/collections/aerial-photos/
- World Historical Gazetteer, date-aware toponym discovery and API: https://www.whgazetteer.org/ ; https://docs.whgazetteer.org/content/technical/apis.html . Beware source-specific redistribution restrictions (451 responses).
- OpenHistoricalMap API: https://api.openhistoricalmap.org/about
- Map Warper, official creator's open-source implementation and live service: https://github.com/timwaters/mapwarper ; https://www.mapwarper.net/ . This rectifies *maps*, not arbitrary perspective street photographs.
- COLMAP (Schönberger et al., CVPR 2016), official code, Windows builds and local GUI: https://github.com/colmap/colmap ; https://colmap.github.io/ . No verified author-hosted interactive upload demo; needs multiple overlapping photographs, excessive for v1.
- GhostViewer browser rephotography demonstration: https://ghostviewer.co.uk/ ; re.photos now advertises AI-powered alignment: https://www.re.photos/en/ . Treat as inspiration, not a historical identification oracle.
- Existing photo/archive tools: Tropy (https://www.tropy.org/), digiKam (https://www.digikam.org/), Immich (https://immich.app/), darktable (https://www.darktable.org/) — useful metadata and nondestructive handling but no substitute for source-linked historical place evidence.

### Creative concept — A street's family album
Select a place and time range; display family photographs alongside dated map layers and independently sourced aerial views, letting users see which buildings and businesses survived or disappeared. Tell a place's history through authentic photographs, without generating an imaginary past. Require rights checks before exporting external images.
