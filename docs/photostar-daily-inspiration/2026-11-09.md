# PhotoStar2 Daily Inspiration — 9 November 2026
## Newsprint Time Machine — the day around the photograph

**Best next idea:** A read-only "On this date / in this place" contextual research drawer that retrieves contemporary newspapers and public records for a photograph's estimated time and location. Unlike Visual Footnotes (object-level museum comparisons) and Place Detective (solving where a photo was taken), this investigates what was happening around an already dated/located family event, while avoiding any claim that the family witnessed the reported news.

### Proposed UI
1. "Around this photograph" drawer: date window, locality, optional topics, and provenance-tagged article results.
2. Three tabs: **Same day** (only if exact date independently established), **Around this time**, **Local history**. Label results "context", "possible event match" or "user-confirmed connection".
3. Time-window-aware search: date estimates of 1955–1965 should not generate a fake "On this day in 1960" result. Rank sources by date overlap, place relevance, source quality and access rights. Never update the photograph date from news matches automatically.
4. Collection navigation: a decade/locality matrix showing which photo groups have useful contextual references; cache text-only citations and source URLs, not copyrighted page scans.
5. Optional story output: a two-column "Our photograph / The wider world" annotated timeline with sources, and a deliberate distinction between personal evidence and public context.

### Sources and comparison
- [The National Archives newspaper research guide](https://www.nationalarchives.gov.uk/help-with-your-research/research-guides/newspapers/) lists British Newspaper Archive, The Gazette, Welsh Newspapers and research-library access routes; some are subscription-only.
- [UKPressOnline](https://ukpressonline.co.uk/) supports date/name/phrase searching, with free previews and subscription full pages.
- [Library of Congress Chronicling America API](https://www.loc.gov/apis/additional-apis/chronicling-america-api/) is a useful openly documented API reference, though US-oriented; the legacy API was retired in 2025.
- [Tropy](https://www.tropy.org/) demonstrates citation-centred archival annotation; [Gramps Web](https://www.grampsweb.org/features/) provides genealogical context; [Immich](https://immich.app/) and [digiKam](https://www.digikam.org/) offer timeline navigation; [darktable](https://www.darktable.org/) keeps nondestructive editing separate from historical evidence.
- [Transkribus official API](https://docs.transkribus.org/start/first-job) and [official interactive upload demonstration](https://website-alpha.transkribus.org/ai-text-recognition) offer OCR/HTR for clipped newspaper pages and handwritten captions; remote processing and paid API tiers require explicit opt-in. The API is a service, not an open model repository.
- [Qwen3-VL official repository](https://github.com/QwenLM/Qwen3-VL) links its official demo, weights and paper; potentially useful for multimodal text/image extraction, but do not infer historical facts from its generated output. Model licence, runtime and actual historical OCR quality need benchmarking. Official code and linked demo exist; no third-party demo is required.

All estimates are provisional. Avoid scraping paywalled newspapers or storing copyrighted page images.

### Creative experiment: Two Clocks
An interactive split timeline: family photographs on one track, dated public events on another. Users can slide between a personal day and the wider world without implying a causal connection. Where a family letter or caption explicitly mentions a news event, a human can promote that link from general context to evidenced connection. This builds a historically honest narrative rather than AI-generated reminiscence.

### Best next experiment
Select 25 independently dated and located photos, 25 photos with decade-only estimates, and 10 deliberate misleading cases. Test manual newspaper searches against proposed generated queries. Measure relevant references per five minutes, date-window false precision, accidental event claims, rights compliance, and user review time. **Start with the read-only search launcher and manual citations**, not an AI agent or bulk newspaper ingestion.
