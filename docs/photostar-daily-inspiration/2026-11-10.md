# PhotoStar2 Daily Inspiration — 10 November 2026
## Search by Example — teach the gallery what you mean

**Best next idea:** Add a temporary relevance-feedback search session: choose a photograph or crop, mark results **More like this / Not like this**, and rerank the next page. Unlike previous Worth Reviewing (which prioritises questions) and Lost Roll (which reconstructs sequences), this improves discovery when a user cannot describe the visual target accurately.

### Repository findings (verified 10 November)

### Proposed UX
1. From any image/crop, **Find visually related**. Results in a virtualised grid; filter by date range, known people, folder, album, historical period, and source/derivative.
2. Mark 2–5 results **closer**, **not this**, or **same event but different subject**. Show a small explanation: visual appearance, same confirmed person, repeated building, shared sequence, etc. Distinguish hard exclusions from soft negative examples.
3. Rerank without changing accepted person IDs, original metadata or stored evidence. Save a named *search recipe* only on request, including example IDs, model version, filters and decisions; invalidate stale vector caches when model changes.
4. Offer **diversify results** to avoid 30 near-identical modern burst images burying rare archival examples.
5. For historic material, compare original crops, not AI-restored images, to avoid matching invented details.

### Implementation/effort (rough)
- Read-only example-based search over existing related-photo features: **3–5 days**, no new model.
- Session-level positive/negative feedback and explainable reranking: **3–6 days**.
- Crop-aware search and mixed metadata filters: **4–8 days**, depending on current crop/vector index.
- Optional CLIP/SigLIP embedding backend and model-versioned cache: **5–12+ days**, subject to performance and licence benchmarks.
- Gallery virtualisation, result diversity and keyboard shortcuts: **3–6 days**.

### Research and software
- [Immich search docs](https://docs.immich.app/features/searching/) combine contextual CLIP with people, OCR, folder, camera, location and date filters; use as a feature reference, not as an architectural transplant.
- [digiKam](https://docs.digikam.org/), [PhotoStructure](https://photostructure.com/), [Tropy](https://www.tropy.org/), [Gramps Web](https://www.grampsweb.org/features/) and [darktable](https://www.darktable.org/) provide complementary examples of similarity/metadata navigation, variants, evidence annotation, people context and non-destructive image editing.
- **VisualReF (RecSys 2025)** [paper DOI](https://doi.org/10.1145/3705328.3759341), [official authors' GitHub](https://github.com/bulatkh/visualref). It combines relevant/irrelevant image examples, CLIP/SigLIP, generated descriptions and Rocchio reranking. Official local Gradio demo source is provided; no verified author-hosted online demo. Its suggested 16+ GB GPU makes the full prototype inappropriate as a baseline for PhotoStar.
- **PinPoint (CVPR 2026)** [paper](https://arxiv.org/abs/2603.04598), [official Pinterest benchmark/code](https://github.com/pinterest/pinpoint-dataset). 7,635 queries and 329K relevance judgements, including hard negatives and multi-image queries. Official evaluation and reranking scripts are runnable locally; no verified official interactive hosted demo. Its benchmarks are not family photographs, so results cannot be directly transferred.
- **FG-CLIP 2 (ICML 2026)** [official authors' repository](https://github.com/360CVGroup/FG-CLIP), [official project page](https://360cvgroup.github.io/FG-CLIP/). Fine-grained visual/text matching, Apache-2.0 repository; inspect individual weights/licences and Windows runtime before adoption. Official examples and project page; no verified interactive hosted demo.

### Creative experiment — Memory Dial
A museum-style visual exploration dial: start from one family photograph and move between **same people**, **same place**, **same objects**, **same visual mood**, and **same period**. The dial changes retrieval weights, not historical truth. The user can follow a recurring wallpaper pattern across houses, a family car through decades, or similar seaside holiday compositions across generations. Show why each photograph appeared and allow a path of selected images to become a cited story trail. Artistic precedent: thematic sequencing and typological photographic series; the tool should preserve surprising juxtapositions without asserting causal relationships.

### Best next experiment
Create a 300-image labelled evaluation set: 50 query examples with positive matches, lookalike hard negatives, different scan variants, poor historical prints and modern bursts. Compare current related-photo ranking against a simple relevance-feedback reranker. Track precision@10, hard-negative@10, diversity, latency, and number of clicks to first useful discovery. **Start with session-only feedback over the existing index**; do not deploy a new embedding model until it proves a measurable gain.
