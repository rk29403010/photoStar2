# PhotoStar2 Daily Inspiration — 12 November 2026
## The Uncertain Timeline — Browse historical photos without pretending dates are exact

**Best next idea:** Add an uncertainty-aware time navigator. Show estimated capture windows as ranges, not false exact dates, and distinguish photographs whose dates are unknown from photographs known not to belong in a period.

### Feature: Uncertain Timeline
1. Date interval bands with a narrow confirmed centre where appropriate; distinguish **confirmed**, **estimated**, **conflicting evidence**, and **undated**. A representative sort timestamp is only a placement hint.
2. Two filter modes: **possibly within** (date window overlaps chosen period) and **definitely within** (entire credible interval contained); undated assets in a separate explicit lane.
3. Decade histogram that displays uncertainty: possible counts versus definitely dated counts, rather than assigning each photo to one arbitrary year. Never add fractional decade counts and call them unique photographs.
4. Evidence drawer shows each date signal, conflicting alternatives, and the reason the estimate changed. Human correction is reversible.
5. Virtualised gallery tied to time brush, with stable ordering and an integration test against the existing filename-sort regression.

### External research and software
- [vis-timeline](https://github.com/visjs/vis-timeline) — official source; [author-maintained interactive examples](https://visjs.github.io/vis-timeline/examples/timeline/). Supports range items and zoom, but DOM density must be benchmarked.
- [SQLite R*Tree](https://www.sqlite.org/rtree.html) — official documentation/source and SQL examples for interval overlap; no hosted interactive demo verified. Algorithm lineage: Guttman 1984 R-tree and Beckmann et al. 1990 R*-tree, as documented by SQLite.
- [HistropediaJS](https://js.histropedia.com/documentation/timeline/) — official documentation and runnable ESM examples; [official timeline site](https://histropedia.com/). Version 1.6.0 released 4 September 2026 with sticky date labels and custom layout improvements. Official code distribution via npm, but no verified public GitHub source repository; check licence before use.
- [Gramps Web](https://www.grampsweb.org/features/) — family event timeline, maps, provenance, undo and source records.
- [Immich search](https://docs.immich.app/features/searching/) — rich combined people/date/metadata search, but typical capture-date filters don't expose PhotoStar-style evidence intervals.
- [TimeMapper](https://github.com/okfn/timemapper) — official Open Knowledge Labs source and [live hosted examples](https://timemapper.okfnlabs.org/), useful for combining time and location.
- [Tropy](https://www.tropy.org/), [darktable](https://www.darktable.org/) and [digiKam](https://www.digikam.org/) — source annotation, reversible editing, collection browsing respectively.

### Creative experiment: Parallel Possible Histories
Present two alternative date interpretations side-by-side (e.g. family recollection says 1948, photo lab envelope suggests 1953) with the images and period context each would imply. The user can examine both without the software inventing a definitive story. As evidence accumulates, one interpretation may become stronger; the discarded one remains auditable.

### Recommended next experiment
Build a read-only date-range filter against 500 synthetic and verified photos: exact dates, decade-only estimates, unknowns, contradictory evidence and imported scan timestamps. Compare false exclusions, gallery query latency, histogram counts and user comprehension against existing single-date sorting. **Ship range semantics before any timeline animation.**
