# PhotoStar2 Daily Inspiration — 15 November 2026

## Collection Atlas — see the shape and blind spots of an entire family archive

**Recommendation:** Prototype a zoomable, read-only Collection Atlas that groups photographs by visual character and overlays known people, estimated periods, locations and evidence quality. Unlike the 10 November example-search proposal, this is an overview-first interface: it answers *what is in the archive, what is overrepresented, and what remains unexplored?*

### Feature design
1. **Atlas overview:** sample a representative, diverse set of thumbnails from each collection partition; use a WebGL/canvas overview and progressive loading, not a DOM node per photograph. A scatterplot is optional, not the only mode.
2. **Switchable lenses:** visual similarity; confirmed people; uncertain decades; locations; scans/restorations. Overlay evidence completeness and proportion of unidentified people, but do not equate missing metadata with low historical value.
3. **Drill-down:** lasso a region to open a virtualized gallery; preserve filters and selection on returning to the atlas. Offer a conventional grid and accessibility-friendly keyboard navigation.
4. **Explainable grouping:** distinguish visual resemblance from verified person/place links. Clusters are navigation aids, not claims about history.
5. **Atlas of absences (experimental):** highlight periods and family branches with sparse coverage and allow a curated narrative of what survives and what is unknown; never generate fictitious missing photographs.

### Research and product comparisons
- VIKUS Viewer: original creator's MIT-licensed code https://github.com/cpietsch/vikus-viewer ; creator-hosted viewer https://vikusviewer.fh-potsdam.de/ . Its multiple layouts, spritesheets and shareable view state are especially relevant; avoid adopting its entire static-site architecture.
- Yale DH Lab PixPlot: project code https://github.com/yaledhlab/pix-plot ; a WebGL image-embedding explorer, useful as a benchmark for tens of thousands of thumbnails. The code is available; a currently functioning author-hosted upload demo was not verified.
- FiftyOne: official similarity and embeddings-panel examples https://docs.voxel51.com/user_guide/app.html and https://docs.voxel51.com/user_guide/similarity.html ; official code https://github.com/voxel51/fiftyone . Its linked selection between scatterplot and gallery is the strongest UX reference. Runnable local demo exists, no verified author-hosted upload demo.
- Meta DINOv2: official research code and pretrained weights https://github.com/facebookresearch/dinov2 ; **official interactive research demo** https://dinov2.metademolab.com/demos . DINOv2 is a candidate only for offline visual embeddings, not for inferring family relationships. Test CPU/Windows performance and model terms before deployment.
- Existing collection tools to compare: digiKam https://www.digikam.org/ , Immich https://immich.app/ , Tropy https://www.tropy.org/ , Gramps Web https://www.grampsweb.org/ , and CollectionBuilder https://collectionbuilder.github.io/ . Combine gallery navigation, archival notes, genealogical evidence and exhibition-like overview rather than copying any product.

### Implementation and test
| Increment | Effort estimate | Acceptance criterion |
|---|---:|---|
| Metadata-only grouped overview | 3–5 developer days | Correct unique-photo counts across overlapping groups |
| Thumbnail sprites/LOD and canvas interaction | 4–8 days | Responsive navigation at 50k photos without full-image loads |
| Lasso-to-gallery and persistent view state | 3–5 days | Selection, filters and back navigation preserved |
| Optional visual embeddings and projection | 5–12+ days | Demonstrable improvement over existing features; no false historical inference |

Use existing indexed features for the first prototype; do not make a new model or vector database a prerequisite. Test 10k, 50k and 100k records with actual thumbnail sizes; measure initial display, memory, frame rate, visual coverage and how quickly users find a previously overlooked cluster. A two-dimensional projection distorts distances and changes with sampling: label it explicitly as an exploration map, not a reliable historical taxonomy.

**Best next step:** A metadata-first Atlas with three switchable lenses (decade, confirmed people, and visual feature) and direct lasso-to-gallery navigation. It is a practical navigation experiment that reuses PhotoStar's existing evidence index and makes large archives more approachable without risking originals.
