# PhotoStar2 daily inspiration — 18 November 2026

## The Object Biography: follow heirlooms across photographs

**Best next idea:** Give users a lightweight, reversible way to link the *same physical object* across different photographs, years and households: a particular chair, car, toy, instrument or piece of jewellery. This is not generic object-class detection. Distinguish “a red bicycle” from “the same red bicycle”.

### Practical proposal
1. **Object pin (2–4 developer days):** from an existing region box, choose “Track this object”; create a stable object ID, label and evidence citation, with no claim of exact identity yet.
2. **Candidate sightings (3–6 days):** query indexed object/vehicle labels, related images, dates and confirmed people. Rank possible matches; require human acceptance to assert same physical item.
3. **Object biography view (3–5 days):** chronological thumbnail strip, owners/locations as *hypotheses*, and an evidence panel; distinguish a dated photograph from the date an object was acquired.
4. **Collection navigation (2–4 days):** filter by recurring object; group sightings without hiding other photographs.
5. **Optional crop-based similarity (5–10+ days):** only after measuring whether object class plus context misses meaningful matches.

### Creative experiment — The Travelling Chair
Start with a chair in a 1940s portrait, follow it into a 1970s living-room photograph, and perhaps a modern photograph after inheritance. Present the three images alongside documented family transitions. Show alternate interpretations when similar-looking chairs may be different items. Never fabricate missing scenes.

### Evaluation
Curate 100 candidate object pairs: true same-object sightings, same-model lookalikes, different crops, faded prints and restored variants. Prioritise false same-object assertions, review time, retrieval precision@10 and explanation quality. Prototype manually before deploying Grounding DINO or SAM 2.

**Recommendation:** Implement manual object identity and candidate review using existing region observations. It offers novel family-history navigation without another heavyweight inference dependency.
