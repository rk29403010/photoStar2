# PhotoStar2 Daily Inspiration — 20 November 2026

## Context Bridge: place family photographs beside verifiable historical material

**Best next idea:** A source-aware *Context Bridge* panel that suggests period maps, local archive photographs, advertisements, newspapers and records relevant to a family photograph's approximate location and date. Unlike an automatic historical caption, every external item stays a separately sourced candidate; no inferred identity or event becomes a fact without review.

### Practical product proposal
1. **Context drawer (3–5 developer days):** From an existing photograph, show separate *Family evidence* and *External context* tabs. Query using a verified place and a **date interval**, not a representative midpoint. Show candidate source title, year, institution, licence and original link. Allow dismiss/keep; never silently write claims.
2. **Period-map and photo comparison (4–8 days):** Open a historical map or street photograph alongside the family image, with synchronized region notes. No fabricated image overlay or forced geolocation. Source attribution persists.
3. **Search across a large collection (3–6 days):** Filter to photos with plausible contextual matches; group by place and period; virtualise results. Use cached source metadata and an explicit refresh action, not live external requests for every thumbnail.
4. **Historical-source evidence record (4–7 days):** Store external URL, provider ID, access date, rights, date range, relation type, reviewer decision and confidence. A source being contemporary does not prove it depicts the same event.

### Software and research comparisons
- [Europeana official APIs](https://api.europeana.eu/en): searchable photographs, newspapers, records and IIIF; free API key required. [Europeana's own Python client](https://github.com/europeana/rd-europeana-python-api) provides official source and runnable examples. The [Europeana collections](https://www.europeana.eu/) are a working public discovery interface, not a PhotoStar integration demo.
- [IIIF Image API](https://iiif.io/api/image/3.0/) and [OpenSeadragon](https://openseadragon.github.io/): standard region/tile access and official interactive viewer examples; useful for contextual side-by-side comparison.
- [Tropy](https://www.tropy.org/): provenance-rich archival research; [Gramps Web](https://www.grampsweb.org/features/): family source relationships; [CollectionBuilder](https://collectionbuilder.github.io/): contextual digital exhibitions; [darktable](https://www.darktable.org/): nondestructive adjustments; [Immich](https://docs.immich.app/features/searching/): combined metadata and visual search.
- [Transkribus official API](https://www.transkribus.org/transkribus-api): official browser upload demo for historical handwriting, but Scholar subscription/credits and cloud processing make it an optional, consent-gated source-transcription tool, not the default. No open-source Transkribus inference codebase was verified; don't imply that the hosted API is local or open source.

### Creative experiment — Two Windows on One Street
A split-screen narrative: left, a family snapshot of a street; right, an independently sourced photograph or map from roughly the same period. Drag a time slider to explore changes, with *what we know*, *what we suspect* and *what we cannot establish* clearly separated. The app could build a short evidence-linked story of a home, shop or journey without inventing any missing images.

### Recommended test
Choose 20 photographs with independently known locations and uncertain dates. Prototype Europeana-only lookup first, and measure relevant source matches per image, false historical associations, rights completeness and reviewer time. Require user confirmation before linking an external source to a family record. Do not integrate handwriting recognition or generative restoration until the retrieval-and-review workflow proves useful.

**Priority:** Build a read-only Context Bridge drawer first. It uses PhotoStar's existing evidence architecture, adds genuinely new historical context and is reversible and testable.
